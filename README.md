# ApparelFlow ERP

Cutting Gatekeeper Verification Terminal — software engineering assessment.

## Stack

Next.js (App Router) · TypeScript · Tailwind · Prisma · PostgreSQL (Supabase)

## Setup

1. Copy `.env.example` to `.env` and fill in Supabase + JWT values.
2. `npm install`
3. `npx prisma migrate dev`
4. `npm run dev`
